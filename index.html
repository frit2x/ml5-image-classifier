ℹ️ Über das Modell

💡 Wie es funktioniert

MobileNet ist ein vortrainiertes Convolutional Neural Network, das 1000 verschiedene Objektklassen (aus ImageNet) klassifizieren kann. Die Klassifikation läuft komplett im Browser, keine Daten werden an einen Server übertragen.

⚠️ Limitierungen

MobileNet funktioniert gut bei klaren, typischen Bildern. Probleme treten bei ungewöhnlichen Perspektiven, schlechter Beleuchtung, mehreren Objekten oder abstrahierten Bildern auf. Dies liegt an Bias im Trainingsdatensatz.

🛠️ Technologie

  • ml5.js – ML-Wrapper für Browser
  • TensorFlow.js – Modell-Backend
  • Chart.js – Datenvisualisierung

Information

Bildklassifikation mit dem MobileNet-Modell – vollständig clientseitig, keine Datenspeicherung.

Datenschutz

Alle Bilder werden lokal im Browser verarbeitet. Es findet keine Datenübertragung zu Servern statt.
