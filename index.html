💬 Diskussion & Ergebnisse

Beobachtungen

Die Klassifikationsergebnisse zeigen deutlich, wie stark die Perspektive und Bildkomposition das Modell beeinflussen. Pinguine von vorne werden zuverlässig erkannt (>90%), während Pinguine von oben völlig falsch klassifiziert werden – das Modell hat auf typische Frontalaufnahmen aus ImageNet gelernt. Ähnlich beim Burger: Die Frontalansicht wird korrekt erkannt, aber sobald der Burger Augen und Zunge erhält (humoristisch manipuliert), verliert das Modell völlig den Bezug und klassifiziert ihn falsch. Das LED-Auto zeigt das extremste Problem: Trotz eindeutiger Auto-Form liefert das Modell keine Verbindung zum Original, weil die visuelle Textur (LEDs statt Lack) zu sehr vom Standard abweicht. Der Sportwagen in Schrägperspektive wird noch erkannt, weil diese Perspektive häufiger im Trainingsdatensatz vertreten ist. Fazit: MobileNet funktioniert gut bei typischen Szenen, bricht aber zusammen bei Manipulationen, unerwarteten Perspektiven oder visuellen Anomalien.

📚 Dokumentation

1️⃣ Technische Implementierung

Verwendete Frameworks & Bibliotheken:

  • ml5.js – High-level API für Machine Learning im Browser. Bietet eine vereinfachte Schnittstelle zu TensorFlow.js und ermöglicht die Klassifikation mit dem MobileNet-Modell ohne tiefe ML-Kenntnisse.
  • TensorFlow.js – Low-level ML-Framework, das im Browser läuft. ml5.js nutzt TFJS als Backend, um das vortrainierte MobileNet-Modell zu laden und Inferenzen durchzuführen.
  • Chart.js – Datenvisualisierungs-Bibliothek zur Darstellung der Klassifikationsergebnisse als horizontales Balkendiagramm mit prozentualen Confidence-Werten.
  • GitHub Pages – Bereitstellung der Web-Anwendung als öffentliche Demo ohne Server-Setup.

Besonderheiten der Lösung:

  • Clientseitige Verarbeitung: Alle Bilder werden lokal im Browser klassifiziert – kein Upload zu einem Server notwendig (Datenschutz!).
  • Interaktive Labels: Unter jedem Beispielbild erscheint sofort das Top-Klassifikationsergebnis mit Prozentangabe, was die Genauigkeit transparent macht.
  • Drag-and-Drop + File-Upload: Nutzer können Bilder per Drag-and-Drop oder Dateiauswahl laden; die Klassifikation startet automatisch.
  • Responsive Layout: Die Anwendung funktioniert auf Desktop, Tablet und Mobile (CSS Grid mit Breakpoints).
  • Zeilenumbruch bei langen Labels: Zeilenumruch beim Klassifikationsnamen, um die Chart-Lesbarkeit zu verbessern.

2️⃣ Fachliche Implementierung

Ansatz:

Die Anwendung nutzt ein vortrainiertes MobileNet-Modell (basierend auf ImageNet mit 1000 Objektklassen), das keine weitere Anpassung benötigt. Der Nutzer kann Beispielbilder interaktiv klassifizieren und eigene Bilder hochladen.

Implementierung der Logik:

  • Modell-Laden: Beim Seitenload wird das MobileNet-Modell asynchron geladen (ml5.imageClassifier('MobileNet')).
  • Klassifikation: Die Funktion classifier.classify(img) gibt ein Array von Objekten zurück: [{label, confidence}, ...].
  • Visualisierung: Die Top-5 Ergebnisse werden mit Chart.js als horizontales Balkendiagramm dargestellt; Confidence wird auf Prozent skaliert.
  • Example-Images: Beim Klick auf ein Beispielbild wird dieses in die Preview kopiert, klassifiziert und das Top-Ergebnis unter dem Bild angezeigt.
  • User-Upload: Hochgeladene oder per Drag-Drop gezogene Bilder werden automatisch klassifiziert und visualisiert.

Ergebnisse & Interpretation:

Die Klassifikationsergebnisse zeigen die Stärken und Schwächen von vortrainierten CNNs: Sie funktionieren exzellent bei typischen, zentrierten Objekten, brechen aber bei Manipulationen, extremen Perspektiven oder visuellen Anomalien zusammen. Dies ist ein Beispiel für Dataset Bias – das Modell hat die Muster des ImageNet-Datensatzes gelernt und generalisiert schlecht auf Abweichungen.
